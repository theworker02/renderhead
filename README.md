# renderhead

Render color head values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/renderhead/

## Install / run

```bash
git clone https://github.com/theworker02/renderhead.git
cd renderhead
node src/cli.js
node --test
```
